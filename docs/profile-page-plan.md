# 개인 프로필 페이지 기획서

## 1. 프로젝트 목표

HTML, CSS, JavaScript를 활용해 사용자의 소개와 주요 정보를 한눈에 확인할 수 있는 반응형 개인 프로필 페이지를 만든다.

## 2. 주요 사용자

- 개인 포트폴리오를 방문한 사람
- 경력과 기술을 확인하려는 채용 담당자
- 연락처와 소셜 링크를 찾는 협업 관계자

## 3. 페이지 구성

### 헤더

- 이름 또는 로고
- 소개, 기술, 프로젝트, 연락처로 이동하는 내비게이션
- 모바일 화면용 메뉴 버튼

### 프로필 소개

- 프로필 이미지
- 이름과 직무 또는 관심 분야
- 한두 문장으로 작성한 자기소개
- 이력서 다운로드 또는 연락하기 버튼
- GitHub, 블로그, LinkedIn 등의 소셜 링크

### 소개 영역

- 자신에 대한 자세한 설명
- 관심 분야와 목표
- 현재 활동 또는 구직 상태

### 기술 영역

- 보유 기술 목록
- 기술별 숙련도 또는 간단한 설명
- 예시: HTML, CSS, JavaScript, Git

### 프로젝트 영역

프로젝트를 카드 형태로 표시한다.

각 카드에는 다음 정보를 포함한다.

- 프로젝트 이름
- 대표 이미지
- 간단한 설명
- 사용 기술
- 데모 및 저장소 링크

### 연락처 영역

- 이메일 주소
- 연락 폼: 이름, 이메일, 메시지
- 입력값 검증 결과와 전송 상태 메시지

### 푸터

- 저작권 문구
- 소셜 링크
- 페이지 상단 이동 버튼

## 4. 디자인 기준

- 단정하고 읽기 쉬운 단일 페이지 레이아웃을 사용한다.
- 모바일 화면을 우선으로 만들고 태블릿과 데스크톱에 대응한다.
- 본문과 배경의 명암 대비를 충분히 확보한다.
- 제목, 본문, 버튼의 스타일을 일관되게 유지한다.
- 콘텐츠의 최대 너비를 제한해 넓은 화면에서도 읽기 쉽게 한다.
- 버튼과 링크에 마우스 오버 및 키보드 포커스 효과를 제공한다.
- 애니메이션은 짧고 자연스럽게 적용하며 사용을 방해하지 않도록 한다.

## 5. 기술별 역할

### HTML

- `header`, `nav`, `main`, `section`, `article`, `footer` 등 의미에 맞는 태그 사용
- 제목 순서를 지켜 문서 구조 구성
- 이미지에 적절한 대체 텍스트 제공
- 폼 요소에 `label` 연결
- 외부 링크에 목적을 알 수 있는 문구 제공

### CSS

- 색상과 간격을 CSS 사용자 지정 속성으로 관리
- Flexbox와 Grid를 활용한 레이아웃 구성
- 모바일 우선 반응형 스타일 작성
- 버튼, 카드, 입력 요소의 공통 스타일 정의
- 키보드 포커스가 분명하게 보이도록 처리
- 사용자가 모션 감소를 설정한 경우 애니메이션 최소화

### JavaScript

- 모바일 메뉴 열기 및 닫기
- 내비게이션 링크의 부드러운 섹션 이동
- 연락 폼 필수 입력값과 이메일 형식 검증
- 폼 처리 결과 메시지 표시
- 필요하면 스크롤 위치에 따른 내비게이션 활성화
- 필요하면 다크 모드 전환 및 사용자 선택 저장

## 6. 권장 파일 구조

```text

├── js/

docs/

```

## 7. 준비할 콘텐츠

- 표시할 이름
- 프로필 사진
- 직무 또는 관심 분야
- 짧은 자기소개와 상세 소개
- 보유 기술 목록
- 프로젝트별 이름, 설명, 이미지, 링크
- 공개할 이메일과 소셜 링크
- 이력서 파일 또는 다운로드 링크

실제 정보가 준비되지 않은 항목은 구현 단계에서 쉽게 교체할 수 있는 예시 문구를 사용한다.

## 8. 구현 순서

1. HTML로 전체 섹션과 콘텐츠 구조를 작성한다.
2. CSS 기본 스타일과 모바일 레이아웃을 적용한다.
3. 태블릿과 데스크톱 반응형 레이아웃을 추가한다.
4. JavaScript로 메뉴와 폼 검증 등 상호작용을 구현한다.
5. 실제 프로필 정보와 이미지를 반영한다.
6. 다양한 화면 크기와 키보드 조작 환경에서 테스트한다.

## 9. 완료 기준

- 소개, 기술, 프로젝트, 연락처 영역이 모두 표시된다.
- 내비게이션으로 각 영역에 이동할 수 있다.
- 모바일, 태블릿, 데스크톱에서 레이아웃이 깨지지 않는다.
- 모든 이미지에 대체 텍스트가 있다.
- 키보드만으로 메뉴, 링크, 버튼, 폼을 사용할 수 있다.
- 연락 폼이 빈 값과 잘못된 이메일 형식을 안내한다.
- 브라우저 개발자 도구 콘솔에 JavaScript 오류가 없다.
- 외부 링크와 다운로드 링크가 올바르게 작동한다.

## 10. 선택 기능

기본 페이지를 완성한 후 필요에 따라 추가한다.

- 라이트/다크 테마 전환
- 스크롤 등장 애니메이션
- 프로젝트 카테고리 필터
- 다국어 전환
- 이메일 서비스 또는 백엔드 API를 통한 실제 문의 전송

문의 폼은 프론트엔드만으로 실제 이메일을 전송할 수 없다. 실제 전송 기능이 필요하면 백엔드 API나 별도의 폼 서비스를 연결해야 한다.
